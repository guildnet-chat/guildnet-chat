# Security

The web chat is part of GuildNet, and its security policy is GuildNet's:
[SECURITY.md](https://github.com/guildnet-chat/guildnet/blob/main/SECURITY.md).

Tell us privately, never in a public issue: through this repository's
**Security** tab (**Report a vulnerability**), or by email to
[security@guildnet.chat](mailto:security@guildnet.chat).
